Git & GitHub Command Guide

Git was created by Linus Torvalds in 2005 to manage the Linux kernel source code. GitHub launched in 2008 as a platform to host Git repositories and enable collaboration around code.

This ordered guide covers Git from definition to GitHub SSH setup and push workflow.

1. Git Definition

Git is a distributed version control system for tracking changes in code and coordinating work across collaborators.

  • git --version - Verify Git is installed.

2. Git Installation and Setup

Install Git, then configure your identity so commits are associated with you.

  • git config --global user.name "Your Name" - Set your author name.
  • git config --global user.email "you@example.com" - Set your author email.

3. Connect Git

Link Git to your local project and confirm it is tracking changes correctly.

  • git init - Initialize a new Git repository.
  • git status - Show which files are untracked or modified.

4. Initialize Git

Create the first commit and establish the local repository history.

git init
git add .
git commit -m "Initial commit"

5. Add Files to Git

Stage files for commit, inspect changes, and make commits with clear messages.

  • git add <file> - Stage a specific file.
  • git add . - Stage all changed files.
  • git diff - View unstaged changes.
  • git diff --staged - View staged changes.
  • git commit -m "Describe your change" - Commit staged changes.

6. Connect GitHub Using SSH

Generate an SSH key, add it to GitHub, then connect the local repo using the SSH remote URL.

Generate or reuse SSH key

ssh-keygen -t ed25519 -C "you@example.com"

Start the SSH agent and add your key

eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519

Add the public key to GitHub

cat ~/.ssh/id_ed25519.pub

Copy the output into GitHub settings: GitHub SSH keys.

Connect the repository to GitHub

git remote add origin git@github.com:username/repo.git

7. Push Code to GitHub

Push your local commits to GitHub and set the upstream branch for future pushes.

git branch -M main
git push -u origin main

Then use git push for subsequent updates.
